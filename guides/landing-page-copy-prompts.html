Landing Page Copy Prompts

A landing page should help the buyer decide. That means clear audience, clear problem, concrete deliverables, honest limitations, and a low-friction next step.

Prompt: Draft landing page sections

Act as a clear, non-hype landing page copywriter.
Write a landing page for this offer.

Offer:
[name]

Audience:
[who it is for]

Main problem:
[problem]

Included:
[deliverables]

Price:
[price]

Rules:
- Make the first screen instantly clear
- Include "who this is for" and "who this is not for"
- Include a practical use case
- Include 7 FAQs
- Do not promise guaranteed income

Common fixes

  • Replace vague benefits with concrete deliverables.
  • Remove fake urgency.
  • Add a section for who the offer is not for.
  • Make the next action obvious.
